2. Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt. GitHub Pages ist ein Dienst von GitHub.

Beim Aufruf dieser Website werden technisch erforderliche Verbindungsdaten verarbeitet. Dazu kann insbesondere die IP-Adresse des aufrufenden Geräts gehören.

GitHub gibt an, dass beim Besuch einer GitHub-Pages- Website die IP-Adresse des Besuchers zu Sicherheitszwecken protokolliert und gespeichert wird.

Die Verarbeitung dieser Daten ist technisch erforderlich, damit die Website ausgeliefert sowie die Sicherheit und Stabilität des Angebots gewährleistet werden kann.

Soweit die Verarbeitung in meinem Verantwortungsbereich erfolgt, stütze ich sie auf Art. 6 Abs. 1 lit. f DSGVO. Das berechtigte Interesse liegt in der sicheren, stabilen und technisch funktionsfähigen Bereitstellung dieser Website.

4. Cookies, Analyse und Tracking

FussConnaisseur verwendet derzeit keine eigenen Analyse- oder Werbedienste wie Google Analytics oder Meta Pixel.

Von mir werden auf dieser Website keine eigenen optionalen Tracking-Cookies gesetzt.

Beim Einsatz externer Dienste können nach einer bewussten Aktivierung durch den Besucher jedoch Technologien des jeweiligen Drittanbieters zum Einsatz kommen.

Dies betrifft auf FussConnaisseur insbesondere den optional eingebetteten YouTube-Player. Weitere Informationen dazu findest du im Abschnitt „Eingebettete YouTube-Inhalte“.

5. Externe Links und Social-Media-Auftritte

Auf FussConnaisseur befinden sich Links zu externen Websites, Diensten und Social-Media-Plattformen.

Dazu können beispielsweise Links zu Twitch, YouTube, Steam, TikTok, Discord oder Instagram gehören.

Bei gewöhnlichen externen Links wird allein durch die Darstellung des Links noch keine Verbindung zur jeweiligen externen Plattform hergestellt.

Erst beim Anklicken eines solchen Links wird die Website des jeweiligen Drittanbieters geöffnet. Dabei können personenbezogene Daten, insbesondere die IP-Adresse und technische Verbindungsinformationen, an den jeweiligen Anbieter übermittelt werden.

2-Klick-Lösung Der YouTube-Player wird beim normalen Aufruf von FussConnaisseur nicht automatisch geladen.

Zunächst wird ausschließlich ein lokal auf dieser Website erzeugter Hinweis mit einer Schaltfläche angezeigt.

Wenn du gleichzeitig bei einem Google- oder YouTube-Konto angemeldet bist, kann Google Informationen über deine Nutzung des eingebetteten Inhalts gegebenenfalls deinem Konto zuordnen.

Das bloße Öffnen von FussConnaisseur führt durch die hier eingesetzte 2-Klick-Lösung noch nicht zum Laden des YouTube-Players.
