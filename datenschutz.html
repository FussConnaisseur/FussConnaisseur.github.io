Datenschutz.

Informationen über die Verarbeitung personenbezogener Daten beim Besuch des Online-Auftritts FussConnaisseur.

1. Verantwortlicher

Verantwortlicher für die Datenverarbeitung auf dieser Website ist der im Impressum genannte Betreiber.

FussConnaisseur ist die Bezeichnung dieses Online-Auftritts. Der Betreiber tritt online außerdem unter der Bezeichnung KohtaKuma auf.

Die vollständigen Angaben zum Verantwortlichen sowie die Kontaktmöglichkeiten befinden sich im Impressum.

→ Zum Impressum

2. Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt. Anbieter des Dienstes ist GitHub, Inc., 88 Colin P Kelly Jr Street, San Francisco, CA 94107, USA.

Beim Aufruf dieser Website werden technisch erforderliche Daten verarbeitet.

GitHub gibt insbesondere an, dass beim Besuch einer über GitHub Pages bereitgestellten Website die IP-Adresse des Besuchers zu Sicherheitszwecken protokolliert und gespeichert wird.

Im Rahmen der technischen Bereitstellung können darüber hinaus insbesondere Verbindungs-, Geräte- und Nutzungsinformationen verarbeitet werden.

Die Verarbeitung erfolgt, soweit sie in unserem Verantwortungsbereich liegt, zum Zweck einer sicheren, stabilen und technisch funktionsfähigen Bereitstellung dieser Website.

Soweit hierfür eine Rechtsgrundlage in unserem Verantwortungsbereich erforderlich ist, erfolgt die Verarbeitung auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO.

Das berechtigte Interesse besteht in der sicheren und zuverlässigen Bereitstellung dieses Internetauftritts.

3. Verarbeitung in Drittländern

Bei der Nutzung von GitHub können personenbezogene Daten auch außerhalb der Europäischen Union beziehungsweise des Europäischen Wirtschaftsraums verarbeitet werden.

Dies betrifft insbesondere eine mögliche Verarbeitung personenbezogener Daten in den Vereinigten Staaten.

Informationen über internationale Datenübermittlungen und die von GitHub verwendeten Schutzmechanismen stellt GitHub in seinen Datenschutzinformationen bereit.

4. Cookies, Analyse und Tracking

Der Betreiber von FussConnaisseur verwendet auf dieser Website derzeit keine eigenen Analyse-, Werbe- oder Trackingdienste.

Insbesondere werden derzeit kein Google Analytics, kein Meta Pixel und keine vergleichbaren Analyse- oder Werbetrackingdienste eingesetzt.

Der Betreiber setzt auf dieser Website keine optionalen Tracking-Cookies ein.

Soweit der Hostinganbieter technisch erforderliche Technologien im Rahmen der Bereitstellung seines Dienstes einsetzt, richtet sich deren Verarbeitung nach den Datenschutzinformationen des jeweiligen Anbieters.

5. Externe Links und Social-Media-Auftritte

Auf FussConnaisseur befinden sich Links zu externen Websites, Diensten und Social-Media-Plattformen.

Dazu können beispielsweise Links zu Twitch, YouTube, Steam, TikTok, Discord oder Instagram gehören.

Es handelt sich dabei derzeit ausschließlich um gewöhnliche externe Links.

Beim bloßen Besuch von FussConnaisseur wird durch diese Links keine Verbindung zu den jeweiligen externen Plattformen hergestellt.

Erst wenn ein solcher Link angeklickt wird, wird die Website des jeweiligen Drittanbieters aufgerufen.

Dabei können personenbezogene Daten, insbesondere die IP-Adresse sowie weitere technische Informationen, an den jeweiligen Anbieter übermittelt werden.

Für die anschließende Verarbeitung auf der externen Website gelten die Datenschutzbestimmungen des jeweiligen Anbieters.

6. Keine eingebetteten Drittanbieter-Inhalte

Auf dieser Website werden derzeit keine Videos, Social-Media-Feeds, Karten, Werbeanzeigen oder vergleichbaren Inhalte von Drittanbieter-Servern automatisch eingebettet.

Insbesondere werden keine eingebetteten YouTube- oder Twitch-Player und keine eingebetteten Social-Media- Beiträge eingesetzt.

Die auf der Website aufgeführten Plattformen werden ausschließlich über normale Links aufgerufen.

7. Schriftarten

Für die Darstellung dieser Website werden derzeit keine Schriftarten von externen Anbietern wie Google Fonts nachgeladen.

Es werden ausschließlich Schriftarten verwendet, die auf dem Gerät des Besuchers verfügbar sind beziehungsweise durch den Browser dargestellt werden.

8. Kontaktaufnahme

FussConnaisseur stellt derzeit kein eigenes Kontaktformular bereit.

Eine Kontaktaufnahme ist über die im Impressum angegebenen Kontaktmöglichkeiten möglich.

Wenn eine Kontaktaufnahme erfolgt, werden die dabei übermittelten Daten zur Bearbeitung und Beantwortung der jeweiligen Anfrage verarbeitet.

Die Rechtsgrundlage richtet sich nach dem jeweiligen Inhalt der Kontaktaufnahme.

Bei allgemeinen Anfragen kann die Verarbeitung insbesondere auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO erfolgen.

Das berechtigte Interesse besteht in der Bearbeitung und Beantwortung der jeweiligen Anfrage.

Soweit eine Anfrage auf den Abschluss oder die Durchführung eines Vertrags gerichtet ist, kann die Verarbeitung auf Grundlage von Art. 6 Abs. 1 lit. b DSGVO erfolgen.

9. Online-Impressum.de

Für die Bereitstellung der im Impressum verwendeten c/o-Anschrift sowie weiterer Kontaktmöglichkeiten wird der Dienst Online-Impressum.de genutzt.

Auf FussConnaisseur selbst werden keine Inhalte dieses Anbieters automatisch eingebettet.

Eine Verbindung zur Website von Online-Impressum.de wird über den entsprechenden externen Link beziehungsweise bei Nutzung des dort bereitgestellten Kontaktwegs hergestellt.

10. Speicherdauer

Personenbezogene Daten, die sich im Verantwortungsbereich des Betreibers befinden, werden grundsätzlich nur so lange gespeichert, wie dies für den jeweiligen Verarbeitungszweck erforderlich ist oder gesetzliche Aufbewahrungspflichten eine längere Speicherung verlangen.

Soweit Daten unmittelbar durch GitHub oder einen anderen externen Anbieter verarbeitet werden, gelten ergänzend die Speicherfristen des jeweiligen Anbieters.

Nach Maßgabe der gesetzlichen Voraussetzungen können betroffene Personen insbesondere folgende Rechte geltend machen:

• Recht auf Berichtigung gemäß Art. 16 DSGVO

• Recht auf Einschränkung der Verarbeitung gemäß Art. 18 DSGVO

• Recht auf Datenübertragbarkeit gemäß Art. 20 DSGVO

Soweit eine Verarbeitung auf einer Einwilligung beruht, besteht außerdem das Recht, die Einwilligung jederzeit mit Wirkung für die Zukunft zu widerrufen.

Soweit personenbezogene Daten auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO verarbeitet werden, besteht unter den Voraussetzungen des Art. 21 DSGVO das Recht, aus Gründen, die sich aus der besonderen Situation der betroffenen Person ergeben, Widerspruch gegen die Verarbeitung einzulegen.

13. Beschwerderecht

Betroffene Personen haben unbeschadet anderer verwaltungsrechtlicher oder gerichtlicher Rechtsbehelfe das Recht, sich bei einer Datenschutzaufsichtsbehörde zu beschweren, wenn sie der Ansicht sind, dass die Verarbeitung ihrer personenbezogenen Daten gegen die DSGVO verstößt.

14. Verschlüsselte Übertragung

Diese Website wird über eine verschlüsselte HTTPS-Verbindung bereitgestellt.

Dadurch werden Daten während der Übertragung zwischen dem Browser des Besuchers und der Website verschlüsselt übertragen.

Diese Datenschutzerklärung wird angepasst, wenn sich die eingesetzten Dienste, Funktionen dieser Website oder die maßgeblichen rechtlichen Anforderungen ändern.
